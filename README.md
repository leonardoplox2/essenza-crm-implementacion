# Implementación del CRM Essenza

Blog del proyecto de implementación del **CRM Predictivo y Retención Postventa** en Essenza SPA. Curso Gestión de Proyectos TI, UNTELS 2026, con el enfoque de la Guía PMBOK® 8.

- Sitio: https://essenza-crm-implementacion.vercel.app
- Secciones: `#inicio` (contexto del proyecto) y `#mapa` (mapa de procesos de Ejecución, Monitoreo y Control y Cierre).

Es un sitio estático: todo el contenido, los estilos y el JavaScript están en `index.html`. No necesita build; Vercel publica el archivo tal cual en cada push a `main`.
